# Files macos/scripts/syntax-check.sh does not attempt to parse.
#
# This is the syntax checker's list of known-hard files, and nothing else. It
# used to be wired into React-Core.podspec and React-CoreModules.podspec as
# `osx.exclude_files` too, which was wrong twice over:
#
#   - It never took effect. `s.macos` and `s.osx` are the same platform proxy,
#     and React-CoreModules assigns `s.macos.exclude_files` further down, which
#     silently replaced it. Every file listed here was being compiled anyway.
#   - Making it take effect breaks the link. RCTDevMenu, RCTActionSheetManager
#     and RCTPerfMonitor are all referenced from CoreModulesPlugins.mm and from
#     RCTRootViewFactory, so dropping them leaves undefined symbols.
#
# They compile on macOS regardless, which is the useful discovery. So the list
# stays advisory: it marks what the checker skips, not what the build omits.
